Политика конфиденциальности

Редакция от 4 ноября 2026 года

Мы уважаем вашу приватность и стремимся собирать минимум данных, необходимых для работы сервиса nimbleVPN.

1. Какие данные мы собираем

1.1. Сервис не требует регистрации и не запрашивает ваши персональные данные (имя, email, телефон).

1.2. При первом нажатии кнопки «Подключиться» в вашем браузере генерируется случайный токен подписки, который сохраняется в локальном хранилище (localStorage). Он используется только для выдачи вам персональной ссылки.

1.3. При подключении к серверу приложение Happ может передавать HWID (идентификатор устройства) для контроля лимита в 3 устройства. Эти данные не содержат личной информации.

1.4. Мы не собираем историю посещений, не логируем IP-адреса и не анализируем трафик.

2. Использование данных

2.1. Токен подписки используется исключительно для идентификации вашей ссылки на сервере.

2.2. HWID используется исключительно для подсчета активных устройств, чтобы не превышать лимит.

2.3. Данные не передаются третьим лицам и не используются в рекламных целях.

3. Хранение данных

3.1. Токен хранится в вашем браузере. Вы можете удалить его, очистив данные сайта.

3.2. Информация о привязанных HWID хранится на сервере в течение срока действия подписки.

4. Cookies и сторонние сервисы

4.1. Сайт не использует рекламные cookies.

4.2. Мы можем использовать сторонние сервисы для хостинга статики (Cloudflare, Github Pages и т.д.), которые могут собирать техническую информацию в соответствии со своими политиками.

5. Изменения

5.1. Мы можем обновлять эту политику. Актуальная версия всегда доступна на этой странице.
